# ЭГ-Демо — прототип системы электронного голосования

Учебный статический сайт, показывающий, как может выглядеть проверяемое
электронное голосование: анонимный бюллетень, квитанция избирателя, публичный
реестр голосов на хеш-цепочке и подсчёт, который может воспроизвести кто угодно.

> **Это демонстрация, а не действующая система.** Проект не связан с
> государственными органами, избирательными комиссиями и официальными
> сервисами, не использует их символику и не собирает персональные данные.
> Голосование не имеет юридической силы. Организации, кандидаты и цифры
> вымышлены. Никогда не вводите здесь паспортные данные, СНИЛС или пароли от
> реальных сервисов.

## Что умеет

| Раздел | Что показывает |
| --- | --- |
| Вход | Идентификатор превращается в анонимный токен `SHA-256`; исходная строка не сохраняется |
| Кабинет | Список голосований, статусы, отметка о поданном бюллетене |
| Бюллетень | Выбор варианта, подтверждение, защита от повторного голосования |
| Квитанция | Код записи в реестре, подтверждение `SHA-256(вариант + соль)`, выгрузка в файл |
| Проверка голоса | Поиск записи по квитанции и доказательство авторства через сохранённую соль |
| Результаты | Подсчёт прямо из реестра, явка, доступная таблица значений |
| Реестр | Последние записи, проверка целостности цепочки, экспорт JSON, демонстрация подделки |
| Как устроено | Разбор схемы и честный список того, чего прототип не делает |

## Как это работает

1. **Вход.** `токен = SHA-256("voter:" + строка)`. Строка нигде не хранится.
2. **Выдача бюллетеня.** В отдельный список попадает `SHA-256(токен + голосование)` —
   он отвечает только на вопрос «брал ли избиратель бюллетень», но не «за что он голосовал».
3. **Голос.** Браузер генерирует случайную соль и пишет в реестр вариант и
   подтверждение `SHA-256(вариант + соль)` — без токена избирателя.
4. **Квитанция.** Первые 16 символов хеша записи. Соль остаётся у избирателя.
5. **Проверка.** По квитанции запись находится в реестре, а соль позволяет
   пересчитать подтверждение и убедиться, что учтён именно ваш вариант.
6. **Целостность.** Каждая запись хранит хеш предыдущей, поэтому правка задним
   числом рвёт связь со следующей записью, а скрыть её можно лишь переписав всю
   цепочку до конца — это видно по кнопке «Проверить целостность».

## Ограничения прототипа

* Личность избирателя не проверяется — достаточно любой строки.
* Голоса не зашифрованы до конца подсчёта (в реальных системах для этого нужны
  гомоморфное шифрование или перемешивающие сети).
* Квитанция вместе с солью позволяет избирателю доказать свой выбор — то есть
  не защищает от давления.
* Реестр не распределённый: он живёт в `localStorage` одного браузера, независимых
  наблюдателей у него нет.
* Сервера нет вовсе — очистка данных браузера стирает и реестр, и вашу соль.

## Стек

Статический сайт без сборки: HTML, CSS и ES-модули. Хеширование — Web Crypto
(`SHA-256`), состояние — `localStorage` (ключ `eg-demo.v1`). Зависимостей нет.

```
index.html              разметка оболочки
assets/css/style.css    оформление, светлая и тёмная темы
assets/js/app.js        маршрутизация по хешу, тема, служебные помощники
assets/js/views.js      экраны
assets/js/store.js      состояние, реестр, подсчёт, проверки
assets/js/crypto.js     SHA-256, случайные значения, квитанции
assets/js/data.js       демонстрационные голосования
```

## Локальный запуск

Нужен http-сервер: ES-модули и Web Crypto не работают при открытии файла с диска.

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Развёртывание

Сайт публикуется на GitHub Pages воркфлоу `.github/workflows/pages.yml`.
Один раз нужно включить Pages: **Settings → Pages → Build and deployment →
Source: GitHub Actions**. Дальше каждый push в ветку деплоя обновляет сайт.

## Доступность

Тёмная тема подобрана отдельно, а не инвертированием. Палитра результатов
проверена на различимость при дальтонизме (ΔE ≥ 8 для соседних пар в обеих
темах), у каждого варианта есть подпись и значение текстом, а также таблица —
цвет никогда не единственный носитель смысла. Есть ссылка «Перейти к
содержимому», видимый фокус, навигация с клавиатуры и `prefers-reduced-motion`.
